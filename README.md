# 한꺼번에 PDF

한글 문서(.hwp, .hwpx)를 **여러 개, 폴더째 한 번에 PDF로** 바꿔 주는 무료 Windows 프로그램입니다.

파일을 인터넷에 올리지 않고, 내 PC에 설치된 한글 프로그램으로 컴퓨터 안에서 직접 변환해요.

## ⬇️ 다운로드

👉 **[최신 버전 받기 (Releases)](../../releases/latest)**

페이지 아래쪽 Assets에서 `HanBatchPDF-0.1.0.zip`을 받으시면 됩니다. 설치는 필요 없어요.

## 준비물

- Windows PC
- **한글(한컴오피스 한글)이 설치되어 있어야 합니다.** 이 프로그램은 PC에 있는 한글을 불러서 변환해요.
  - 한글 2014, 2024에서 정상 작동을 확인했어요.
  - 한글 2018·2020·2022와 구독형은 아직 확인하지 못했어요. 써 보시고 알려 주시면 큰 도움이 됩니다!

## 사용 방법 (3단계)

1. **압축 풀고 실행** — 받은 zip 파일의 압축을 풀고 `HanBatchPDF` 폴더 안의 `HanBatchPDF.exe`를 실행합니다. 변환할 HWP 파일이나 폴더를 창에 끌어다 놓거나 **[파일 추가…]·[폴더 추가…]** 로 고르세요. (`HanBatchPDF.exe` 아이콘에 바로 끌어다 놓아도 목록에 들어가요)
2. **저장 위치 선택** — **[원본 문서가 있는 폴더에 저장]** 하거나, **[다른 폴더에 저장]** 을 고르고 **[저장 폴더 선택…]** 으로 지정한 폴더에 모아 저장할 수 있어요. (폴더째 넣었다면 하위 폴더 구조도 그대로 유지돼요)
3. **[N개 PDF로 변환] 클릭** — 한글이 뒤에서 조용히 하나씩 PDF로 바꿔 줍니다. 결과 표에서 완료·실패·건너뜀과 그 이유를 볼 수 있고, **[결과를 엑셀로 저장]** 으로 결과표를 CSV로 남길 수 있어요.

💡 **무료 버전은 한 번에 최대 10개까지** 변환합니다. 10개가 넘으면 이번에는 10개만 변환할지 물어보고, 끝난 뒤 **[남은 N개 변환]** 을 누르면 완료된 파일은 빼고 아직 안 한 파일부터 다음 10개를 이어서 바꿔 줘요. 실패한 파일만 남으면 버튼이 **[실패한 N개 다시 변환]** 으로 바뀝니다.

## 내 파일은 안전한가요?

- 문서 파일을 **어디에도 업로드하지 않습니다.** 모든 변환은 내 PC 안에서만 이루어져요.
- 원본은 건드리지 않고 복사본으로 변환해서 PDF만 새로 만듭니다.
- 사용자가 열어 둔 한글 창도 건드리지 않아요. 변환용 한글을 따로 띄웁니다.
- ※ 관공서나 기업처럼 사내 보안 규정이 엄격한 곳에서는 외부 프로그램 사용이 가능한지 먼저 확인해 주세요.

## "Windows의 PC 보호" 창이 떠요

처음 실행할 때 **"Windows의 PC 보호"** 창이 뜨고 게시자가 **"알 수 없는 게시자"** 로 나올 수 있어요.
개인이 만든 무료 프로그램이라 유료 코드 서명 인증서를 붙이지 않아서 생기는 안내입니다.

실행하려면 창에서 **[추가 정보]** 를 누른 뒤 **[실행]** 을 누르시면 됩니다.

## 알려진 제한

- **암호가 걸린 문서**는 변환하지 못해요. 암호 창을 띄우지 않고 그 문서만 '실패'로 표시한 뒤 다음 문서로 넘어갑니다.
- 그림을 문서 안에 넣지 않고 원본 옆 폴더의 그림 파일에 **'연결'만 해 둔 문서**는 PDF에서 그림이 빠질 수 있어요. 이런 문서는 만들어진 PDF를 한 번 열어 확인해 주세요.
